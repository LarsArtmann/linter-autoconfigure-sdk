"chore: auto-commit 2 changed file(s) (heuristic)".** This is permanent:
the tag is pushed, history is immutable, force-push is banned.

- Root cause: MY sequencing. I edited CHANGELOG/README and then ran
  buildflow (minutes) BEFORE committing. The daemon (15:37:56) raced me and
  committed with its heuristic message. By the time I looked, amending was

  immediately rewording it as a proper `chore(release): v0.7.0` commit.

  shows a heuristic message for the release commit. The release CONTENT is
  verified correct (CI, verify-release.sh, API smoke), so this is a
  history-hygiene failure, not a correctness failure.
